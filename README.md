# Wave Generator

A lightweight, browser-based waveform generator for creating and exporting WAV audio files.

**Languages:** 简体中文 / 日本語 / English  
**Author:** itsukiMNE  
**Version:** v0.19 Public

## Features

- **Four waveforms:** Sine, Square, Triangle, and Sawtooth
- **Pitch selection:** C2–B5, with a frequency display
- **Waveform variation:** Adjustable period and amplitude variation, with an option to regenerate the random pattern
- **Noise:** Adjustable noise level
- **Preview and playback:** View the resulting waveform and listen to the generated sound
- **WAV export:** 44,100 Hz, 16-bit PCM, mono
- **Multilingual interface:** Switch between Simplified Chinese, Japanese, and English

The default settings are **Sawtooth** at **D4**. The interface opens in **Simplified Chinese**.

## Getting started

1. Download the files and keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a modern browser.
3. Choose a waveform and pitch.
4. Adjust the variation and noise settings as needed.
5. Use **Play** to listen, **Stop** to stop playback, or **Export WAV** to save the audio.

No installation or server setup is required.

## 使用方法（简体中文）

将 `index.html`、`style.css` 和 `script.js` 放在同一文件夹中，用浏览器打开 `index.html` 即可使用。

选择波形和音高，根据需要调整周期波动、振幅波动和 Noise。可以预览波形、试听声音，并导出 WAV 文件。页面右上角可以切换语言。

## 使い方（日本語）

`index.html`、`style.css`、`script.js` を同じフォルダーに保存し、ブラウザーで `index.html` を開いてください。

波形と音高を選び、必要に応じて周期・振幅のゆらぎや Noise を調整できます。波形のプレビュー、試聴、WAV ファイルの書き出しに対応しています。画面右上から表示言語を切り替えられます。

## Export format

- Sample rate: **44,100 Hz**
- Bit depth: **16-bit PCM**
- Channels: **Mono**
- Filename example: `Sawtooth_D4_.wav`
